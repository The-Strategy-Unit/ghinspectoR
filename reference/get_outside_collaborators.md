# Retrieve outside collaborators

Retrieves outside collaborators for a GitHub organisation. Outside
collaborators have access to specific repositories but are not
organisation members.

## Usage

``` r
get_outside_collaborators(org, token = get_token())
```

## Arguments

- org:

  A single character string giving the GitHub organisation or username
  whose repositories should be retrieved.

- token:

  A GitHub installation access token or personal access token. The
  default is \`get_token()\`, which returns a token generated by the
  GitHub App.

## Value

list user objects returned by the GitHub API.

## Examples

``` r
if (FALSE) { # \dontrun{
get_outside_collaborators(org = "my-org")
} # }
```
