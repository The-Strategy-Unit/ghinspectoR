# Retrieve organisation teams

Retrieves teams (grouped members) within a GitHub organisation.

## Usage

``` r
get_teams(org, token = get_token())
```

## Arguments

- org:

  A single character string giving the GitHub organisation or username
  whose repositories should be retrieved.

- token:

  A GitHub installation access token or personal access token. The
  default is \`get_token()\`, which returns a token generated by the
  GitHub App.

## Value

list user objects returned by the GitHub API.

## Examples

``` r
if (FALSE) { # \dontrun{
get_teams(org = "my-org")
} # }
```
