# Retrieve organisation members

Retrieves all members of a GitHub organisation.

## Usage

``` r
get_members(org, token = get_token(), limit = Inf)
```

## Arguments

- org:

  A single character string giving the GitHub organisation or username
  whose repositories should be retrieved.

- token:

  A GitHub installation access token or personal access token. The
  default is \`get_token()\`, which returns a token generated by the
  GitHub App.

- limit:

  The maximum number of repositories to retrieve. The default is
  \`Inf\`, which retrieves all available repositories.

## Value

list user objects returned by the GitHub API.

## See also

\[tidy_members()\]

## Examples

``` r
if (FALSE) { # \dontrun{
get_members(org = "my-org")
} # }
```
